# README - PIPELINE MAESTRO COMPLETO
## INTEGRACIÓN, IGC Y MODELADO DE VIDA ÚTIL HDM-4 (MTC V5.2 - COMPARATIVO)
## TRAMO HUANCAVELICA - PALCA (PE-26)
================================================================================

Este script Python (**pipeline_maestro.py**) es una herramienta de análisis que integra la condición superficial (PCI), la rugosidad (IRI), y las cargas de tráfico (ESALs) con parámetros de diseño estructural y ambiental (Módulos de Resiliencia, Temperatura, Coeficientes HDM-4) para:
1.  Determinar el estado actual del pavimento (PCI, IRI).
2.  Establecer la correlación estadística entre PCI e IRI.
3.  Proyectar la carga de Ejes Equivalentes Acumulados (ESAL_N).
4.  Calcular el **Índice de Condición Global (IGC)**.
5.  Modelar y proyectar la **Vida Útil de Diseño** del pavimento flexible mediante los métodos **HDM-4** (tradicional y calibrado) y generar las curvas de deterioro.
Nota: Para poder leer bien el readme, es mejor ponerlo en pantalla completa.

## 3. METODOLOGÍA DETALLADA Y FLUJO DE TRABAJO INTERNO
--------------------------------------------------------------------------------

El script (pipeline_maestro.py) procesa los datos en 5 fases secuenciales, donde cada fase es insumo de la siguiente:

FASE 1: Cálculo del PCI (ASTM D6433)
- Lógica Principal: El código utiliza las funciones get_dv_for_distress y compute_cdv_from_tdv_q para interpolar el Valor de Deducibilidad (DV) a partir de la Densidad (%) y las curvas estándar (DV_CURVES) (L, M, H) para cada tipo de falla.
- Fórmula Final: Para cada unidad de muestreo, el PCI se calcula como: PCI=100-DV

FASE 2: Procesamiento y Promediado del IRI
- Lógica Principal: La función aggregate_iri_by_segment estandariza las unidades y calcula el promedio del IRI por cada segmento para cada recorrido.
- Consolidación: Se realiza un merge outer de todos los recorridos cargados.
- Resultado: Se calcula el IRI Promedio Total y la Desviación Estándar por segmento, asegurando la robustez de la medición.

FASE 3: Correlación Estadística (PCI vs IRI)
- Integración: Los resultados de PCI e IRI.
- Análisis:
	. Pearson (r): Coeficiente de correlación para medir la fuerza de la relación lineal..
	. Regresión Lineal (OLS): Se ajusta la línea PCI = Pendiente*IRI} + Intercepto y se calcula el R^2 (Coeficiente de Determinación) para validar la relación estadística.
- Salida: Gráfico de dispersión con la línea de regresión y una tabla de resumen estadístico.

FASE 4: Cálculo de ESALs Acumulados (ESAL):
- Cálculo del FC: FC = sum (Porcentaje_i * FEA_i, se obtiene del archivo de clasificación vehicular.
- Interpolación del IMDA (Atenuación): El IMDA se interpola linealmente para cada progresiva (K) del segmento, entre el IMDA_máx (Punto A) y el IMDA_mín (Punto B).

			ESAL_N=365 x IMDA_base x FC x Fe x FDC X [((1+r)^L-1)/r]
	El FDC (Factor de Distribución por Carril) se ajusta automáticamente según la entrada de 'Carriles en Dirección de Diseño'.

FASE 5: Modelado de Deterioro HDM-4 y Cálculo del IGC

Esta es la fase crítica donde se integran los parámetros ambientales y estructurales para simular la proyección de deterioro (IRI, Fisuración, Ahuellamiento) a lo largo del periodo L.


Parámetro Clave                                    Rol en el Modelado HDM-4
MR​ (Geología)           "Estructural/Fatiga: Se utiliza para estimar la capacidad estructural del pavimento, afectando directamente los parámetros de deformación de la base y subrasante. Un MR​ bajo acelera la fatiga y la progresión del ahuellamiento por deformación permanente."
Tavg​ (Clima)            "Ahuellamiento/Viscosidad: La temperatura media anual es un factor directo en la ecuación de ahuellamiento de HDM-4. Una Tavg​ más alta reduce la rigidez del asfalto (módulo de elasticidad), incrementando la velocidad de progresión del ahuellamiento por flujo plástico."
Kc​ (Modelo)             "Calibración: Coeficiente que multiplica el término basal de las funciones de deterioro (e.g., incremento de IRI, de fisuración) para ajustar la sensibilidad del modelo HDM-4 a las condiciones de Huancavelica - Palca."

- Cálculo del IGC: Se calcula el Índice de Condición Global para el estado inicial, ponderando los índices obtenidos y la carga acumulada:
- Proyección HDM-4: El código itera año por año, proyectando el deterioro (IRI, fisuración) en función del ESAL proyectado para ese año, ajustando las tasas con M_R, T_avg y K_c.
